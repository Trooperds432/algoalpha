# 12.2 Software Engineer — ALG-450

Implemented the bounded opaque SourcePackage validator for coordinator ALG-443.
Only source_package.py, its focused unit tests, and these two role artifacts are
owned by this assignment. Public isolated admission remains unchanged and disabled.

The frozen dataclass checks direct construction and payload construction: nonempty
UTF-8 source, protocol.MAX_SOURCE_BYTES encoded limit, exact lowercase 64-hex SHA256
matching source bytes. Invalid surrogate Unicode raises DomainError. Payloads require
exactly source/source_sha256/dependencies, string keys, and an empty list for
dependencies. Each serialization returns a fresh dictionary and dependency list.
Source stays opaque, including syntactically invalid Python and NUL text. The validator
does not parse, compile, import, execute, stage, extract or write supplied source.
