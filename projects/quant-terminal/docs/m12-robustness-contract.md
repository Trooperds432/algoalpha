# M12 robustness and overfitting toolkit contract

## Objective

Expose fragile research conclusions by rerunning immutable M8/M9/M10 strategy identities under explicit, bounded perturbations and summarizing parameter neighborhoods. The toolkit is a diagnostic, not a promotion rule, strategy approval, or claim of durable alpha. It never submits broker orders.

## Perturbation specification and execution

An immutable `RobustnessSpec` pins a unique analysis ID, baseline M8 manifest/result fingerprint, strategy and project source hashes, dataset snapshot identities, interval, currency, starting capital, benchmark and analytics settings, execution assumptions, and a list of typed scenarios. The base run is retained as the control. Each scenario records its unique ID, category, exact changed fields/values, declared rationale, and any dates, instruments, or parameter neighborhood membership. Only the listed fields may change; all other baseline identity fields must remain fixed. Currency, source and dataset identity cannot change within a comparison.

Initial scenario categories: parameter values and local grid neighbors; commission increase; adverse-slippage increase; fixed delayed signal/execution observations for one or more completed bars; start-date truncation; end-date truncation; contiguous subperiods; declared market-regime partitions; and explicit instrument-universe inclusion/exclusion. Each scenario executes through a caller-supplied trusted M5/M6/M8 adapter and produces an immutable M8 run. Preserve all outcomes including invalid, failed, unavailable and infeasible scenarios with reasons. Storage, identity, data-integrity, or source mismatch errors stop the campaign; trial-local execution failures remain visible and do not delete other results. No execution-side assumption is inferred from the changed label: exact configuration values and effective dates are required.

The delay scenario uses a typed `bar_delay` overlay: a nonnegative integer number of completed source bars by which strategy observation is delayed, with original `available_at` and actual observation time retained. Historical bar price/timestamps remain unchanged; history queries are capped at the original observation cutoff. Decisions and order acceptance occur at the delayed observation time; fill price/time come from later executable original bars under M4. Initial delay support is single-instrument with strictly increasing source availability. The right-censored pending observation tail is counted explicitly; an excessive delay leaving no observable bars or a delayed order with no executable remaining bar fails visibly. Dataset snapshots and source hashes remain unchanged, and the overlay is pinned in M8 configuration and checked against result metadata. Unsupported or ambiguous timestamp mappings reject. The trusted adapter verifies executing source files and the project source bundle before and after every run.

Date/subperiod/regime/universe comparisons must declare the sample interval and retained observations. Overlapping observations are not independent samples. Survivorship, point-in-time universe membership, adjustment/dividend conventions and calendar compatibility are inherited from the pinned M2 dataset and cannot be repaired by a robustness label. Instrument-universe perturbation is rejected when compatible versioned instrument data is unavailable.

## Sensitivity surfaces and neighborhood stability

Construct deterministic response surfaces from complete M9 trial identities and M6 metric records. A parameter neighborhood is defined by explicit adjacent choices in the declared finite parameter grid; no distance is invented for untyped or categorical values. Report eligible, failed, infeasible, and unavailable counts per cell, metric units, and source fingerprints. Neighbor stability reports the fraction and distribution of available neighbor outcomes meeting the same explicitly supplied comparison threshold; it is descriptive and is never a new optimization objective. Missing cells remain missing. A narrow isolated peak must remain distinguishable from a broad plateau.

Scenario deltas compare each result with its control using identical named M6 formulas, currency and units. Ratios are unavailable when the baseline is zero or undefined. Date and regime subsets recompute M6 on their actual retained observations, elapsed interval, and sample size and declare insufficient-sample states. The periodic annualization convention remains pinned; full-sample elapsed duration and statistics are not reused. Missing values are not filled with zero. Results include all input and output fingerprints and the exact scenario manifest.

For a complete-grid diagnostic, callers must pass `declared_levels` from the original M9 parameter specification. The backwards-compatible observed-only neighborhood cannot discover omitted levels and must not be represented as complete-grid evidence. `diagnose_plateau` uses an absolute metric-decline tolerance, declared maximize/minimize direction, and contiguous eligible cells; the selected center is excluded from the available-neighbor stability fraction. A better adjacent cell identifies a non-optimal center. These are local sensitivity descriptions, not statistical evidence of generalization.

## Bootstrap uncertainty and Sharpe diagnostics

Bootstrap confidence intervals are conditional on the supplied time series and named resampling method. Use M11's deterministic resampler and preserve confidence level, sample period/frequency, block length or trade-frequency assumption, seed, valid/invalid replicate counts, and interval convention. A bootstrap interval is not a posterior probability or proof of future performance.

Probabilistic Sharpe Ratio may be reported only from an adapter-attested dated periodic excess-return sample. The typed sample binds all M8 source run IDs, source and adapter-attestation fingerprints, currency, named frequency, periods per year, risk-free basis, benchmark identity/annual benchmark Sharpe, UTC timestamps, contiguous source-period indices, and exact excess returns. The adapter must prove timestamp/session-index alignment, benchmark and currency compatibility, and risk-free derivation against the M8 calendar and analytics settings. Gapped session indices reject. The initial PSR is conditional on the user's explicit IID, non-overlapping periodic-return assumption; a test that fails to reject autocorrelation does not establish independence. Overlapping observations or diagnostics that flag material serial dependence make PSR unavailable until a separately specified effective-sample-size or HAC-adjusted method is validated. Use the Bailey-Lopez de Prado finite-sample expression `PSR = Phi((SR - SR*) * sqrt(n - 1) / sqrt(1 - skew * SR + ((excess_kurtosis + 2) / 4) * SR^2))`, where `SR` and threshold `SR*` are per-period, skew is the standardized third central moment, and excess kurtosis is standardized fourth central moment minus 3. The M12 initial implementation requires `SR` computed from the same per-period excess-return observations used for moments; an annual benchmark Sharpe is converted to a per-period target by dividing by `sqrt(periods_per_year)`. Require at least 30 valid periodic observations for the first implementation, label this as a conservative minimum rather than proof of estimator precision, and report sample size/moment uncertainty; reject nonpositive/undefined denominator and inadequate sample rather than clamp. The normal CDF uses the versioned Python `statistics.NormalDist` implementation and must be tested against reference values. Methodology reference: Bailey and Lopez de Prado, "The Sharpe Ratio Efficient Frontier" (2012), which develops PSR and identifies the IID track-record setting and non-normal moment adjustments; https://papers.ssrn.com/sol3/papers.cfm?abstract_id=1821643.

Deflated Sharpe Ratio is in the owner's M12 investigation/design scope. It requires a defensible effective number of independent trials and an expected-maximum Sharpe model; raw grid size is not an independent-trial count. Initial M12 retains a prerequisite report bound to the complete M9 trial population, including failed and noneligible candidates, and reports DSR unavailable. Numerical implementation awaits verified aligned dated trial-return inputs and independently validated dependence correction. No caller-provided count alone enables a number. These prerequisites and limitations are exposed to consumers; PSR remains a conditional single-series diagnostic, not a correction for selection bias.

White's Reality Check is deferred: M8 M7 report artifacts can contain dated NAV chart points, so the underlying history may be recoverable, but there is no first-class verified common-frequency, synchronized candidate-versus-benchmark differential-return artifact or dependence-preserving White-bootstrap contract and acceptance fixture yet. It must not be approximated from Sharpe values. Purged/embargoed cross-validation is also deferred until an ML feature/label interval model exists. No unsupported statistic is emitted as a placeholder value.

## Canonical artifact and safety

Emit a canonical artifact binding the complete specification, baseline identity, scenario list, M9 campaign/trial population identity, M8 result identities, per-scenario metrics/status/reasons, sensitivity surfaces, perturbation deltas, uncertainty assumptions and computed diagnostics. Identical inputs and code version reproduce identical economic outputs; elapsed runtime is informational and excluded from deterministic result fingerprints. Artifacts are suitable for M8 retention. The implementation cannot provide an adversarial sandbox for strategy callbacks; only trusted local adapters are supported before M16.

## Verification and exit gate

Verify immutable spec identity and scenario-only changes; repeat determinism; complete capture of failed/unavailable trials; parameter adjacency and missing-cell surfaces; broad plateau versus isolated optimum fixtures; cost/slippage/delay/date/subperiod/regime/universe perturbations; mismatched currency/source/dataset rejection; annualization and insufficient-sample handling; PSR reference calculations and invalid denominators; DSR refusal without defensible trial metadata; bootstrap identity/coverage; artifact tamper/fingerprint checks; and zero broker/order side effects. The exit gate requires a synthetic fixture where a narrow optimum is distinguishable from a broad stable region, with all scenarios reproducible and limitations visible.

## Explicit deferrals

White's Reality Check awaits aligned candidate return series; purged/embargoed validation awaits typed ML label/feature intervals. Effective-trial-count estimation beyond explicit, independently justified supplied assumptions is not inferred from candidate count. Neither M12 nor its outputs authorize live trading or capital allocation.
