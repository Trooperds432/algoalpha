Read docs/roadmap.md and coordination/milestone-state.json before mutation.

uses the owner's PROJECT NAME.txt as its specification; the PDF is architectural context.

until its conventions are documented and the next gate is authorised.
Do not move to a later milestone because your individual task is complete.

is not evidence that an agent ran, reviewed software or interacted with the terminal.

at once, each on distinct files; schema, lockfile and interface changes are serialized.

but no strategy forward test, order or live connection is authorised by this build.
No credentials in source, prompts, manifests, reports or strategy workers.
No paid external-model routing or services as a consequence of plugin selection.

Preserve failed experiments and tests. Never change golden economic outputs silently.
Keep ledger values exact and document undefined metrics. Do not claim a Python
read-only object is an adversarial sandbox. Trusted strategies only before M16.
